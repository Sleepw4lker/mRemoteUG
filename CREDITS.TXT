mRemoteUG
=========

mRemoteUG is a fork of mRemoteNG, maintained by Uwe Gradenegger.
Upstream: https://github.com/mRemoteNG/mRemoteNG

Nearly all of the code in this application was written by the people listed
below, for mRemoteNG and, before it, for mRemote. This fork narrows the scope
and modernises the platform; it takes nothing away from their work, and the
licence it is released under is theirs as well - GPL v2, see License.txt
(COPYING.TXT in the source).

Entries were removed from the component lists at the end of this file only
where the component itself is no longer shipped. Nobody was removed from the
lists below.
